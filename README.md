# 26 November 2026: Giza tanker fire kills 31

A single 1024×1024 image summing up world news of Thursday 26 November 2026: the Giza fuel tanker fire (31 dead) as the lead story, plus the Dow Jones crossing 50,000 for the first time, Macy's 100th Thanksgiving parade postponed by a severe storm, a FedEx cargo jet running off the runway in Miami, and the EU's planned €50 billion technology fund.

The image is drawn programmatically with Python + Pillow (`draw_entry.py`); `main.ts` copies `entry.png` to the output directory.
